# Roboten

Programmeringslek för barn 4–7 år. Lägg pilar i raden, tryck på den gröna knappen — roboten gör precis
det du säger, även om det blir tokigt. Prickarna på brädan visar vägen innan roboten går.

- 7 handdesignade nivåer med stenar, dammar, frukter och en nyckel.
- Inget förlusttillstånd: roboten tutar, skakar på huvudet och programmet finns kvar.
- Stora tryckytor, allt på svenska, ljud via WebAudio — inga ljudfiler.
- Spelas på iPad (porträtt och landskap) och med mus.

Öppna `index.html` i en webbläsare. `test.html` kör de automatiska testerna.
Se `DESIGN.md` för lärandemål, objektlista, motor och nivåer.
